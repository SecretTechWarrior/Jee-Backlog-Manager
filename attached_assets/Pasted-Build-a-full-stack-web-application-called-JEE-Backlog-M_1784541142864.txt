Build a full-stack web application called "JEE Backlog Manager".

The purpose of this application is to help a JEE aspirant manage lecture backlogs for both Class 11 and Class 12 separately. This is NOT a task manager or to-do list. It is specifically a lecture backlog tracker.

========================
TECH STACK
========================

Use:

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Node.js
- Express
- SQLite using Prisma ORM

Store everything permanently inside SQLite.

DO NOT use localStorage except for temporary UI preferences.

The application should work completely offline after installation.

Use a responsive layout.

Support Light Mode and Dark Mode.

========================
GENERAL STRUCTURE
========================

There are only two classes.

Class 11
Class 12

Each class contains exactly three subjects.

Physics
Chemistry
Mathematics

Each subject contains unlimited chapters.

Each chapter stores lecture information.

========================
RULES
========================

Remaining lectures should NEVER become negative.

Completed lectures should NEVER exceed Total lectures.

Whenever completed lectures increase,

Remaining = Total - Completed

Whenever total lectures increase,

Remaining automatically updates.

Never calculate incorrectly.

Always validate user input.
